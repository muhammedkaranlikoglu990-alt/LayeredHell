## 1. Floors & world

Floor scene name: `GameConstants.FloorSceneName(f)` -> `Floor_M04 … Floor_M01, Floor_P00 … Floor_P45`. Each floor scene contains exactly one root GameObject with a
`FloorChunk` component (floor index serialized). The chunk generates its own content at runtime from modular prefabs (`ModelLibrary`) deterministically
(seed = floor * 7919 + 17) → streaming keeps only current floor ±1 loaded (additive scenes), unload beyond ±2.
